# MSc-Project

This repo contains the work for the MSc Statistics research project at Imperial College London.

The code for reproducing the research is contained in `04_code` using the dataset from https://csr.lanl.gov/data/cyber1/. It is structured as follows: 

- The `feature_construction` folder contains the code for the summary statistics on the data and the plots of the features
- The `choosing_k` folder contains the code to select the optimal k
- The `jaccard` folder cotains the code to compute the jaccard index
- The `ARI`, `VI,` and `PSI` folders contain the code pipelines to produce the clustering stability results
- The `ablation_analysis` folder contains the code for the ablation analysis
- The `composite_stability` folder contains the code to compute the composite stability index



A list of the LLM prompts used in the research can be found in `LLM_prompts.md`.
