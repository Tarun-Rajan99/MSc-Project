# MSc-Project

This repo contains the work for the MSc Statistics research project at Imperial College London.

The code for reproducing the research is contained in `03_code` using the authentication dataset from https://csr.lanl.gov/data/cyber1/. It is structured as follows: 

- **`feature_construction`**:
  - `data_summary_stats.ipynb` — computes summary statistics for the authentication data.
  - `feature_engineering.ipynb` — feature engineering and EDA plots 

- **`choosing_k`**
 

- The  folder contains the code to select the optimal k
- The `jaccard` folder cotains the code to compute the jaccard index
- The `ARI`, `VI,` and `PSI` folders contain the pipelines to produce the relevant clustering stability results
- The `composite_stability` folder contains the code to compute the baseline composite stability index
- The `ablation_analysis` folder contains the code for the ablation analysis
